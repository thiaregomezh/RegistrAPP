# RegistrAPP 📱

Sistema de gestión de asistencia mediante códigos QR desarrollado como proyecto académico para la asignatura **Programación de Aplicaciones Web** de la carrera **Ingeniería en Informática - Duoc UC**.

RegistrAPP es una aplicación que permite gestionar la asistencia académica mediante autenticación de usuarios, generación de códigos QR y registro de asistencias. El proyecto fue desarrollado aplicando conocimientos de desarrollo frontend, backend, manejo de datos y consumo de servicios.

## Funcionalidades

- Inicio de sesión de usuarios.
- Generación de códigos QR para asistencia.
- Registro de asistencia mediante lectura de QR.
- Visualización de asignaturas.
- Consulta de asistencias registradas.
- Cambio de contraseña de usuarios.

## Tecnologías utilizadas

**Frontend:** Ionic, Angular, TypeScript, HTML5, CSS3 y JavaScript.

**Backend:** Node.js y JSON Server.

**Herramientas:** Visual Studio Code, Git/GitHub y Linux.

## Instalación y ejecución

Clonar el repositorio:

git clone https://github.com/thiaregomezh/RegistrAPP.git

Instalar dependencias:

npm install

Ejecutar el servidor de datos:

node server.js

Ejecutar la aplicación:

ionic serve
